# 📦 Smart Business Inventory & Sales Tracker

An intelligent ERP and inventory tracking platform featuring an **Agentic AI Workflow** with safe backend tool-calling, built with Python, Django (MVT), and PostgreSQL.

## 🚀 Tech Stack

- **Backend:** Python 3.12, Django 5.x (MVT Architecture)
- **Database:** PostgreSQL (Normalized Schema 3NF)
- **Frontend:** HTML5, CSS3, Modern JavaScript (ES6+ Fetch API)
- **AI Integration:** Agentic LLM Tool Calling (Function Calling)
- **Version Control:** Git & GitHub (Conventional Commits)
